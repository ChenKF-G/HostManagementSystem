第十四章 返回格式（这一章必须做）

也是你刚刚想到的。

建议统一：

{
    "code": 200,
    "message": "success",
    "data": {}
}

失败：

{
    "code": 400,
    "message": "IP地址非法",
    "data": null
}

不要每个接口返回都不一样。

可以封装

Result

例如

Result.success(data)

Result.fail(msg)

↓
